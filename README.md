# Planes Engenharia — MVP Gestão de Obras

MVP funcional da plataforma digital de gestão de obras da Planes Engenharia, usando Japaratinga Resort — Expansão 3 como obra piloto.

## Executar localmente

```bash
node serve.mjs
```

Abra `http://localhost:8787`.

## Módulos

- Visão Geral
- Linha de Balanço
- Médio Prazo
- Plano Semanal
- Produção
- Restrições
- Relatórios

> Os status e percentuais que não puderam ser derivados diretamente das planilhas de origem são tratados como cenário demonstrativo do MVP.
