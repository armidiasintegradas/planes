# Planes Gestão — Japaratinga Resort

MVP funcional da plataforma digital de gestão de obras da Planes Engenharia.

## Acesso de demonstração

- Engenharia: `engenharia@planes.demo`
- Campo: `campo@planes.demo`
- Diretoria: `diretoria@planes.demo`
- Senha para todos os perfis: `Planes2026!`

O login desta versão é destinado apenas à demonstração. Apontamentos e validações são persistidos no navegador do dispositivo.

## Dados

A interface usa atividades, frentes, torres, pavimentos, datas, percentuais e restrições extraídos das planilhas `LINHA DE BALANÇO_PLANEJAMENTO JAPARATINGA_16.03.26.xlsx` e `MÉDIO PRAZO JAPARATINGA R4.xlsx`.
