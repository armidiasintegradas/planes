# PLANES — UX Mobile/Tablet V2

Status: protótipo para validação. Não substitui a interface atual.

## Princípios
- O usuário não deve aprender o Planes; o Planes deve aprender o usuário.
- Home responde: o que aconteceu, o que precisa de atenção e qual a próxima ação.
- Alvos de toque críticos >= 44 px.
- Funções importantes devem aceitar toque, ação rápida ou conversa.
- Brita/Castanha acompanham o contexto da tela.
- Linguagem humana, contemporânea e profissional.
- Conteúdo progressivo por perfil.
- Mobile: uma coluna e ação rápida.
- Tablet: master/detail quando fizer sentido.

## Padrões universais
- Tela interna: voltar sempre previsível.
- Bottom sheet: X visível + toque fora para fechar.
- Formulário longo: Cancelar / título / Salvar.
- Alteração operacional: resumo + confirmação.
- Sucesso: feedback discreto; fechamento automático quando seguro.
- Erro: manter o contexto e indicar o próximo passo.

## Protótipo
Arquivo: prototype-mobile-v2.html

Telas-modelo:
1. Home — Minha obra hoje.
2. Planes Intelligence persistente.
3. Canteiro — registro em 4 passos.
4. Validações — inbox + evidência; master/detail em tablet.

## Personalização do Intelligence
Perfil individual aprende:
- resposta curta vs detalhada;
- voz vs texto;
- módulos mais acessados;
- assuntos recorrentes;
- horários;
- ritmo de comunicação;
- contexto recente e pendências.

Brita/Castanha mantêm traços próprios, mas o estilo do usuário tem prioridade.

## Regra central
O usuário não precisa aprender a falar com o Planes. O Planes aprende a falar com o usuário.
